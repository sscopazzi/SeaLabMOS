# Contributing

Contributions are welcome. Each one is accepted under the licence of the files it changes (see
`LICENSE`). Sign off every commit (`git commit -s`). Signing off certifies the Developer Certificate of
Origin 1.1 (https://developercertificate.org): you wrote the change, or otherwise have the right to
submit it under these licences. New files need an SPDX header, or an entry in `REUSE.toml`. `z_v1/` is
an archive: don't change it.

Before you open a pull request, run `reuse lint` at the repository root (`pip install reuse`). It must end
"compliant with version 3.3 of the REUSE Specification".
